# Moon Turbo Downloader (MTD) ⚡

An **IDM-style download manager for Windows** — fast segmented downloads with browser integration.

## Features

- ⚡ Multi-connection segmented downloading for maximum speed
- 🧩 Browser integration via the companion Chrome extension (`mtd-extension.crx`)
- 🔄 Auto-update channel (`mtd-update.xml`) so the app and extension stay in sync
- 🖥️ Native Windows desktop experience

## Install

1. Install the Windows app from the [**Releases**](https://github.com/Moon-2482/MTD/releases) page.
2. Load `mtd-extension.crx` into Chrome/Edge (Developer mode → Load unpacked / drag & drop) to enable one-click "Download with MTD".

## Files in this repo

| File | Purpose |
|---|---|
| `mtd-extension.crx` | Companion Chrome extension for browser integration |
| `mtd-update.xml` | Update manifest checked by the app and extension |
